THE PRODUCT
The product has two parts.
Build the library once. Read every packet with it.
AI is used in both parts. Code decides. A person signs. The AI never denies.
PART 1
Build the policy library
Policy owner. Once per service, and whenever a policy changes.
OUTSIDE SOURCE
Official policy
CMS, federal rules, Humana documents
AI
Read and draft
ETL + AI reads it, AI drafts the rules
PERSON
Check and approve
Code checks, a person approves
CODE + DATA
Link and publish
Policy to codes to a service, versioned
Part 2 only ever uses what Part 1 approved
PART 2
Read every packet
Intake, nurse and medical director. Every request.

Upload

Read the pages

CODE

AI
Read and check
AI reads details, code checks the evidence
CODE
