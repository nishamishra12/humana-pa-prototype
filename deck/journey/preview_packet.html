A provider sends the request packet by fax or portal. The intake coordinator uploads it as one PDF. Nothing changes here.
An ETL step with AI inside chooses how to read each page, typed text or scan, and splits it into typed pieces with their place on the page.
The procedure code on the request picks the service. If no service uses it, the case is flagged 'No policy yet'. Nothing is guessed.
An AI fills one form, the details this service needs. It reads three times and the answers must agree. If it cannot tell, it says so.
Plain code finds each quoted sentence on its page. A second AI call checks that the sentence supports the claim.
The rules engine is plain code. Missing: pend. Unsure: verify. A rule not met: escalate. All met: approve. There is no deny.
