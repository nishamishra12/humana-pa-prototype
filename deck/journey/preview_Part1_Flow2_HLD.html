KEY FACT One thing a nurse must find in a packet to apply a rule: a name and type, the exact policy sentence, and the question to ask the provider if it is missing.
The owner picks a policy: from CMS, eCFR, or a PDF.
Unstructured parses it into elements, as JSON.
Claude Sonnet drafts the rules, exact quotes, key facts and questions.
Code checks every quote and number against the policy.
The owner approves, edits or rejects each rule.
Approved rules and key facts are saved as a new version.
